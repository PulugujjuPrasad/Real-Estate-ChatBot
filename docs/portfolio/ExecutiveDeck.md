## Section 3: The Intelligence (The "How")
**Slide 7: The AI Strategy**
- Concept: "Strict Grounding."
- Logic: NLP for Intent $\to$ Hard-coded Query for Truth.
- Result: Zero Hallucinations.

**Slide 8: High-Level Architecture**
- Diagram: React $\longleftrightarrow$ Express $\longleftrightarrow$ MongoDB.
- Key: Decoupled Intelligence Layer.

**Slide 9: Data Synthesis Pipeline**
- Process: JSON Fragment A + B + C $\to$ Unified MongoDB Document.
- Value: Reducing latency from $O(N \cdot M)$ to $O(1)$.
